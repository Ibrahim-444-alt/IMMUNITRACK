# IMMUNITRACK - Vaccination Management System

IMMUNITRACK is a web-based Vaccination Management System developed using PHP and MySQL. It helps patients book vaccination appointments, hospitals manage appointments and COVID tests, while administrators oversee the entire system.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/Ibrahim-444-alt/IMMUNITRACK.git
```

2. Copy the project to the XAMPP `htdocs` folder.

3. Start Apache and MySQL.

4. Import `vaccination_system.sql` into phpMyAdmin.

5. Update the database connection if required.

6. Open the project in your browser.
