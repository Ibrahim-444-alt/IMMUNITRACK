# IMMUNITRACK - Vaccination Management System

IMMUNITRACK is a web-based Vaccination Management System developed using PHP and MySQL. It helps patients book vaccination appointments, hospitals manage appointments and COVID tests, while administrators oversee the entire system.

## Features

### Admin Panel
- Admin Login
- Dashboard
- Manage Hospitals
- Manage Patients
- Manage Appointments
- Manage Feedback
- Activate/Deactivate Hospitals
- Profile Management

### Hospital Panel
- Hospital Registration & Login
- View Booked Appointments
- Generate COVID Reports
- Cancel Appointments
- Manage Profile

### Patient Website
- User Registration & Login
- Book Vaccination Appointment
- View Hospital List
- COVID Test Information
- Download Reports
- Contact Us

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Installation

1. Clone the repository

```bash
git clone https://github.com/Ibrahim-444-alt/IMMUNITRACK.git
```

2. Copy the project into the XAMPP `htdocs` folder.

3. Start Apache and MySQL from XAMPP.

4. Import `vaccination_system.sql` into phpMyAdmin.

5. Update database connection settings if required.

6. Open the project in your browser.
